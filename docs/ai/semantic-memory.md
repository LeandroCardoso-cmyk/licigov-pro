# Semantic Memory — Sprint 4.6

## Overview
Memória institucional persistente baseada em correlações semânticas entre chunks.

## Link Types
- **correlation**: Chunks semanticamente relacionados
- **reuse**: Reutilização de cláusulas/padrões
- **precedent**: Precedentes jurisprudenciais
- **contradiction**: Conflitos detectados
- **evolution**: Evolução temporal de conteúdo

## Use Cases
- Memória municipal: histórico de licitações anteriores
- Correlação jurisprudencial: decisões relacionadas
- Reutilização de cláusulas: padrões organizacionais
