# Prompts de Workflows

Prompts relacionados aos workflows documentais e de importação do LiciGov Pro.

## Tópicos

- Workflow state machine documental (draft → in_review → approved/rejected → archived)
- Workflow de importação (uploaded → queued → ... → awaiting_review → approved)
- PolicyEngine e regras de transição por role
- Lock workflow (soft/hard locks)
