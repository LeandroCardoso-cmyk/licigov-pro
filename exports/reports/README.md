# Exports — Reports

Relatórios exportados do sistema para análise e auditoria.

## Tipos de Relatório

- Relatório de conformidade por organização
- Histórico de importações com métricas
- Relatório de retenção e documentos próximos de purge
- Activity log exportado por período

## Formato

Relatórios são exportados em: CSV, XLSX, PDF

## Geração

Relatórios serão gerados via Sprint 5 (Dashboard + Analytics).
